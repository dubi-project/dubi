## 固定产品约束

- 默认最简：自动 Node/Store/Volume/Raft 身份；无 YAML、逐节点 ID 或副本数设置。
- 默认 Store `/var/lib/dubi`，未显式指定卷才登记 `<store>/volume`；失卷不创建空替代卷。
- 各 Engine/Tenant 可以混写同一个 Pack；不按能力分目录、分卷或分 Pack。
- 多 Tenant 的授权和隔离在底座边界落实；Project 不作为集群资源。
- 备份/恢复面向底座持久资源，模块业务导入/导出独立。新节点通过普通 Join、Raft Snapshot 追赶和 Placement/Repair 恢复，不复制旧 Raft 身份。
- 健康观察不能缩小持久多数门槛；多 Volume 不冒充独立 Node/Region。读写可用性、数据仍有拷贝和多数派确认分别验收。

- P03/P07 首批闭环：Root/Engine 文件快照、三节点 mTLS 追赶、启动时按 Raft 引用恢复、自动快照集合登记与关闭顺序。Root 加入目录双向关联预检和同引用崩溃恢复屏障；80 MiB 测试使用正式 Server/Node/enginestate 和真实磁盘 Pack，但运行于本机临时目录；物理掉电/WAN 资格尚未完成。
- P03 发送超时补强：自动区分传输无进展与持久安装等待，按文件大小增加安装/总余量并设有限上限，不增加部署参数。mTLS 测试覆盖停止接收、慢安装、永不 ACK 和取消回收；对端无限闲置流、安装进度协议和真实 WAN 验收仍未完成。
- P04 首批实现：按完整 Keyspace 绑定事务和读取视图；同名键跨 Tenant/Dataset/Engine 隔离而物理 Pack 继续混写；状态/快照 v3 及恢复前 Fence、归属和结果校验。旧格式拒绝且不自动迁移；内部节点 mTLS 不能替代尚未实现的用户授权。
- P05 授权首批闭环：grant 只持久公有摘要；并发消费/撤销单一赢家、失响应重试、绑定后签发失败恢复；客户端 ticket 限时、规范编码和固定 CA/CSR，临时角色不能使用 Node RPC。真实 mTLS 与正式 Server 集成覆盖叶证书签发/安装、越权/错误 CA 拒绝和准入取消；仍不是 CLI 加入或 Root learner 完整流程。
- P05 恢复补强：无 secret 的持久加入回执支持 grant 过期后的安装恢复；Root 加入待办和 learner 协调核心支持提交/成员变更失响应、重启重放、完成后拒绝自动重加已移除成员。历史快照先重放已提交成员尾部再判断资格，Root 路由来自其真实 ConfState。
- P05 网络接线：正式 Server 无需 signer 即可接纳/发现 Root；Node mTLS 精确核对 CSR 公钥和当前证书有效期，拒绝临时角色及同身份异公钥。客户端固定回执 CA、有界重试并验证原子路由视图；后台并行恢复 Root/数据 Group 待办，Begin 后客户端消失无需再次触发。修复仅按 GrantID 生成幂等键导致错误请求占位的问题。CLI、voter 策略与完整拓扑冷启动仍未完成，不能将远端接纳当作整条加入链路完成。
- P05 地址前置校验：以真实 mTLS 回归先复现 `0.0.0.0:7444` 被接受并消费 grant，再统一 CSR/issuer/peer 地址规则；不可用地址在创建本地身份或消费凭证前即拒绝，仍可用同一未消费凭证提交正确请求。不以语法通过替代网络可达性证明。
- P05 本地恢复记录：`DUBI_ROOT_JOIN` 保存身份/Store/回执绑定、接纳/激活位置和单调地址视图；首次发布与激活更新共八个进程退出边界及三轮竞态验证。读取非托管/损坏目录的身份前置检查不再创建锁文件。正式 Node 已接入空 learner、重放检查、应用位置等待和 ReadIndex 后持久激活；双节点覆盖离线源下初次中断、压缩后的文件快照追赶、单节点重启、全部停止后无 signer/ticket/bootstrap 恢复。仅单 voter 加 learner，同机验证不代表跨区域多数可用性。
- P02 生命周期补强：Server 关闭先取消并等待启动恢复、RPC listener 和后台成员任务退出，再关闭传输与 Runtime；并发 Close 等待同一完成结果。Runtime 关闭也等待本地 Group 恢复退出。监听器在启动等待 leader 时失败可中断启动并保留真实原因，不发布 Ready。阻塞文件系统调用仍无法被上下文强制中断。
- P05 默认启动接线：首节点按实际监听/本地路由自动推导发布地址，Root 确认自身登记后才 Ready；重启复用既有 Region/地址，冲突不能静默覆盖，加入节点不能自创缺失的登记。正式 CLI 自动加载 init 既有签发器，真实 mTLS 测试可创建 grant。网络推导不发送探测包，也不证明 NAT/WAN 可达；一步加入 CLI、受控地址变更和证书生命周期仍待完成。
- P05 凭证管理 CLI：`join token/revoke` 使用运行服务与本地 Node mTLS，不离线绕过 Root；客户端校验响应 Cluster 和固定 CA，失响应有限重试同一公有 draft。回归修复了终态拒绝被映射为 Unavailable 的问题，已撤销凭证不再无效重试。测试覆盖创建/撤销、响应丢失、同请求重入、响应替换 CA/Cluster 拒绝及诊断不泄漏 bearer secret。
- P05 自动加入 CLI：`join --ticket-file` 接通自动身份/地址/卷、远端签发、持久回执、Root 接纳和运行；监听端口连续保留，流程锁与运行 Store 锁分离。回执后不再需要 bearer；已接纳重启不调用签发器/Join RPC。测试覆盖真实 mTLS 加入、双节点全停重启、原身份重试、回执断点、显式双卷不创建默认卷、锁冲突，以及损坏/丢失加入记录时拒绝资源重建。仅本机单 voter 加 learner，不是跨区域多数策略或生产资格。
- P05 会话有效期补强：普通 Node RPC 每次授权检查历史已验证链的当前有效期，含 CA；管理/加入在 quorum 等待前后刷新，临时 enrollment 同样检查完整链。真实 mTLS 测试保持同一连接，以可控授权时钟验证过期后的拒绝。快照流在接收前后及 ACK 前重新授权，过期数据/EOF 不发布文件工件；已持久安装但 ACK 时过期不回滚状态。修复文件导入 EOF 错误丢失原因导致权限拒绝被误报 Unavailable 的问题。此实现不是证书吊销、自动续期、主动断开空闲连接或接收 idle 限制。
- P02/P03 接收端保护：首帧等待 10 秒/最多 8 个，数据帧及 EOF 空闲 2 分钟，接收/安装总上下文按大小计算且不超过 24 小时。阻塞 Recv worker 最多 10 个，超时 handler 返回后由 gRPC 关闭流；worker 到实际退出才归还资格，防止积累。真实 mTLS 用例不主动 EOF，覆盖首帧缺失、半途停发、等待 EOF、持续小包不延长总期限、慢本地安装不受网络 idle 误杀、头部槽耗尽仍可心跳，以及资源/worker 回收。不是全局连接/解码预算，也不能强制中断阻塞磁盘。
- P02 RPC 关闭屏障：真实 RPC 回归先复现 gRPC 默认 Stop 在处理函数退出前返回、从而提前释放 Store 的问题；正式 Server 现在显式等待 handlers。等待前先取消 Node 级恢复上下文，但不关闭存储，避免处理函数等待恢复取消而关闭流程又等待处理函数。测试验证清理阻塞期间 Host/Store 保持有效，完成后才释放；BeginShutdown 可重复调用且不释放资源。

- P05 安装重试及续期原语：回归先复现同身份异 CA/公钥的安装重试被接受，再固定原信任根/公钥并保留已安装证书，清理错误不再吞掉。本地叶证书续期仅原子替换证书、不改 CA/私钥/身份，固定目录、独占写锁、有界读取、单调有效期和不确定发布重试；覆盖三个发布阶段的故障/进程退出、并发和目录替换。到期边界统一为 `now < NotAfter`。远端续期授权、后台调度、TLS 热加载及轮换/吊销尚未接线，不是自动续期完成声明。

- P05 凭证管理成员资格：真实 mTLS 回归复现未接纳/已移除 Node 仍能管理 grant，现已改为 ReadIndex 后原子读取当前 ConfState 与 Node 描述符；覆盖 learner 正常使用、移除后复用既有连接拒绝且不提案、历史登记保留，以及 Root 不确定提交/恢复/关闭栅栏。并不替代全局吊销、维护栅栏或已接受操作与后续移除之间的原子序列化。

- P05 双向 TLS 热加载：正式 CLI 服务端/出站客户端共用托管叶加载器，固定原 CA、公钥、身份与目录，按新握手节流刷新并拒绝有效期回退；一次性客户端同步改用受限 descriptor 读取。真实 TLS 覆盖两端收到新叶，竞态覆盖刷新/回调，坏候选保留未过期缓存但到期拒绝。尚未自动申请续期、刷新活动连接或接通统一错误诊断。

- P05 自动叶续期闭环：独立 Node-only RPC 从真实 mTLS 取旧叶/公钥，签发前后 Root ReadIndex 并原子确认调用者与签发者成员资格，拒绝临时角色/未接纳/移除/过期，客户端固定 CA/身份验证且不写 Store。正式运行时后台执行本地或远端续期，内部周期、有限上下文和抖动退避，不分发 signer。真实双节点验证两种自动续期、私钥/CA 不变和重启；补齐 RPC 槽/取消、签发后移除、失败恢复及关闭时等待续期再释放 Store 的测试。仍需活动连接更新、CA 轮换/吊销、签发器 HA 和真实时间/故障域资格。

- P05 连接生命周期闭环：正式内部 Server 默认约 6 小时 GOAWAY 更新，旧流有限宽限；所有正式内部 TLS transport 保留标准握手验证并按当前已验证链有效期关闭底层连接，宽限不越过证书/CA 期限。真实 mTLS 验证到期后双方重新握手使用新叶，正式 Server 构造器验证新请求切换、旧流保留及有限关闭；另测阻塞读释放、时钟跳变与过期明文丢弃。仍不替代 CA 轮换/吊销、全局连接预算或真实时钟/WAN 长时资格；本条更新前述阶段记录中的活动连接缺口。

- P06 成员晋升底层安全条件：先用真实 Raft 状态/持久日志与可控链路断开复现“learner 曾追平、断联后没有新写入，仍可晋升”的缺口；现于同一 Group 锁内同时检查 RecentActive 和当前 Commit 的 Match。拒绝时不追加日志、不改变成员，原多数可继续提交；重连重新确认活跃且追平后可晋升。该观察不保证随后不会失联，也不是自动 voter 选择、稳定区域参与集合或数据耐久性证明。

- P06 自动 Root 拓扑：目标由已接纳成员/Region 推导，优先保留既有 voter，不把失联节点从分母剔除；旧/新 voter 全部活跃追平才提交带 ConfState CAS 的联合变更，本地 leader 降级前先转移，多余 voter 保留为 learner。joint 日志支持中途重启恢复。正式运行流程自动调度，无用户票数参数；全局数据 Placement/Repair 和所有故障组合的可用性仍未实现，单个平面 Root Raft 不能证明分层 Node/Region 多数的全部组合。

- P05/P06 自动拓扑过渡恢复：九节点测试暴露首次 Enroll 对临时 Root 未确认不重试，已用真实 mTLS 回归复现并加入固定请求/凭证的有限指数退避；权限、参数和压力拒绝不重试，保持服务端幂等授权。管理凭证测试在 Leader 过渡时重复同一个公有 draft，不创建替代凭证。

- P06 区域集合持久目录：新增 planned/current 分离、代际 CAS、不可变历史、Node/Region 和 Group 唯一归属，只允许增加参与节点，不按健康缩小分母；确认目录和命令结果/applied 同步原子提交。回归覆盖真实 Root Raft 重启、不确定 Sync 结局和文件/内联快照关联损坏。旧内联 Root 快照同时补齐与文件格式相同的语义校验。尚未建立实际区域 Group、确认追平或接通数据耐久回执，不把目录断言当作业务数据证明。

- P06 自动初始区域 Group：Root 当前成员原子视图驱动持久 formation 计划，原参与节点独立建组/恢复，全部原始成员通过真实读屏障与成员检查后发布路由。普通 cohort 不授予 bootstrap，learner 打开必须有 Root 成员任务，首发前禁止任务抢占；失联不缩小集合，轮转检查不阻塞其他区域。真实三/九节点测试覆盖单节点失效与全群冷启动，另覆盖计划未发布时重启、两种快照和关闭等待。测试发现并修正远端 RPC 客户端不允许检查本机而卡住发布的问题。本条更新上条的初始建组缺口；cohort 仍不 confirmed，未接通自动扩展、数据耐久回执或修复。

## 本地基础门禁

区域栅栏持久原语已接入通用数据 Group：精确成员位置防止名单 ABA 后复活旧栅栏，命令结果/栅栏/applied 原子同步，两类快照核对关联与固定切点；三/九节点真实 Raft 验证提交、逐节点应用及重启。状态格式为 v4，旧开发格式不自动迁移。认证远端观察、初始第一代自动提案、全员协调及 Root 确认已接通，不能把 Active 或 confirmed 当数据多数回执。详见[区域栅栏](architecture/region-fences.md)。

远端观察补强：指定参与者 mTLS、前后 Root 原子成员资格确认、数据 Group ReadIndex 与本地应用切点、响应身份/配置/位置/Active 独立校验；8 个槽、10 秒上下文和有界消息，不增加部署参数。真实连接验证移除后拒绝复用，专项覆盖等待后的移除/授权失效、伪造响应、超限、超时、取消和槽回收；三/九节点回归在故障和冷启动后实际跨节点查询。不是全局吊销或业务回执。

初始集合自动确认：Root 单切点计划/成员任务/当前资格、稳定成员位置绑定 fence、全员精确应用观察、最后复验与 Root Apply 再检查；逐区轮转、失联不缩容、提案失响应/接管复用原 fence、持久暂时拒绝后使用新 Root 切点重试。真实三/九节点测试改由正式后台提案和确认，专项覆盖观察及提交竞态、错误位置/记录、任务互斥、取消和关闭等待。该阶段没有自动推进增长计划，不能替代 active/pending 数据代际交接、每笔数据回执或 Placement/Repair。

成员变更入口补强：原任务身份/epoch 随 Add/Promote/Remove 传递，Root 在同一切点核对任务与当前调用者/服务节点资格，Raft 在提案锁内比较实际成员位置与配置；本地控制同样受约束。旧请求、错任务/角色、等待后授权失效和成员 ABA 均拒绝；真实 Raft 重启验证、mTLS 连接移除后复用拒绝、并发槽和取消回收纳入回归。三节点快照测试新增由正式成员任务完成两节点加入/晋升，再检验追赶与恢复的成员位置。没有升级 enginestate v4，但内部 wire 增加必需字段，尚无混版本协商；这不是完整维护、自动扩容或生产资格完成声明。

成员任务链补强：PrepareJoining 将原始任务传至 Node 工厂，TransferLeadership 绑定任务、成员切点与 leader term，内部转移重试再次检查；等待后重新确认 Root/TLS 资格，旧任务和旧确认响应不复活。三类变更操作共用准入与超时。新增真实三节点空 Group leader 退出/重入，再进行大快照与恢复测试；不等于已实现业务数据 Drain、自动区域缩容或全局授权原子性。

区域增长持久原语：v5 数据状态加入旧代际封口、下一代候选绑定和 Root 精确断言激活，业务 mutation 在未激活或成员位置失效时拒绝，空 Range 控制初始化不解除写入门禁；重启、两类快照和 Sync 不确定结局保持该边界。认证远端观察已包含同切点交接记录与必需格式版本，拒绝错误绑定与旧响应。正式自动增长协调、Root 任务授权和数据多数回执仍待接通，后台仍仅自动确认第一代；见[区域代际交接](architecture/region-handoff.md)。旧 v4 状态明确拒绝，没有执行迁移。

本地 Group/Raft 创建栅栏已加入故障重复门禁：Store 级 Group 登记、日志内外身份及原始 formation；覆盖十四个子进程退出边界、并发创建、缺失/替换资源拒绝及 Root/数据 Group 不重复 bootstrap。区域自动初始建组、计划恢复与真实三/九节点拓扑亦纳入重复门禁；不属于完整 P06/P07 完成声明。
