# Store 磁盘压力保护

Raft Host 默认打开 Store 文件系统压力保护，不增加启动配置。底座沿用 Byfile 的“新工作提前拒绝、恢复有迟滞、已提交复制继续”的原则，但采用 DUBI 自己的身份和错误边界。

每次新提案前读取已固定 Store 目录描述符的容量，并复验路径仍是同一目录。可用空间到达 `max(1 GiB, 总容量 / 20)` 时立即拒绝；目录丢失、被替换或容量无法确认同样失败关闭，不建立空目录。解除压力需要达到保留线再加 `max(64 MiB, 总容量 / 100)` 的恢复余量，并连续三次通过、每次至少间隔 250 ms。请求堆积或频繁查询状态不能把三个瞬时采样算作恢复。

检查覆盖 Host 管理的全部 Root/数据 Group：本地提案、领导者收到的转发提案、成员变更提案和主动创建快照。底层独立 Group 是内部原语，调用方自行提供 guard；正式服务经 Host 自动装配，内部扩展 guard 只能追加限制，不能关闭默认磁盘检查。

ReadIndex、读取已持久状态、选举/心跳、领导权转移、日志复制和已提交快照安装不受新工作准入阻断。预留空间就是为了继续这些必要操作，避免把提前背压做成永久无法追赶。真实 IO 仍可能失败，此时原有状态机/日志的失败关闭契约继续生效。

Root 与 capability 状态机的同步提交返回错误时，不能推断“没有落盘”：当前实例进入需要重开的失败状态，拒绝后续目录/任务/数据/Result 读取、修改和快照。重开依据真实持久 applied/conf/result 恢复，不按内存 index 猜测。测试分别注入未提交即报错和实际提交成功后报错，覆盖 Root 普通命令、成员信息与快照恢复；这不等于已通过真实介质的掉电验证。

直接由准入失败返回的内部 RPC 使用 `ResourceExhausted`，带 30 秒 RetryInfo；它不是 peer `Unavailable`，现有客户端不能因这一状态在同一轮立即换节点继续压入。探针失败也归入暂时不可接收新工作的状态。普通 Raft 转发本身不是业务回执协议；最终业务成功仍须以精确 RequestID 的持久结果确认，不能以一个 ReadIndex 或消息发送成功替代。

`Host.DiskStatus()` 提供内部诊断：路径、总量/可用量、保留/恢复线、连续健康采样数、压力开始时间、采样时间和最近探针错误。`dubi doctor` 负责给出集群/节点是否需要介入的结论；它不会把普通健康状态误报成“所有数据可写”。控制面 Ready 不表示所有卷可写；外部数据 Volume 容量由其 Registry/Pool 管理，不与 Store 盘状态混为一谈。

这是提前拒绝机制，不是物理预分配，也没有为每个 Raft/WAL/Pebble 字节做预约。并发在途日志、已提交 Apply、其它程序、文件系统写时复制或配额仍可能耗尽空间。Pack 的进程内预约与 Store guard 尚未合并为全引擎预算，不能宣称绝不 ENOSPC。外部卷不会替 Store 上的控制元数据补充容量。

恢复办法是增加 Store 所在文件系统容量，或释放明确不属于 DUBI 的文件；不得手动删除 Pack、Raft、Pebble 或身份文件。未授权时，测试不会填满用户的真实磁盘。

本地验证覆盖保留线、整数溢出检查、探针失败、目录替换、并发探针、恢复迟滞、多个 Group 拒绝新写但保留 ReadIndex、三 Voter 复制及压缩日志后的快照追赶，以及 RPC 分类/重试信息。这些故障注入不代替隔离目标盘上的真实填盘、fsync 失败及恢复演练；生产清单 P01 保留目标环境验收项。

## 开发机安全实验

开发机剩余空间很多时，不要为了触发压力保护去填满真实文件系统。仓库提供一个只用于本地开发的隔离实验：

```sh
bash scripts/disk_pressure_lab.sh
```

脚本在 macOS 使用临时 APFS 稀疏镜像，在 Linux 使用临时 ext4 镜像（Linux 需要有挂载权限）；默认创建 2 GiB 的实验文件系统，把该文件系统的可用空间压到 1 GiB 保留线以下，然后验证新的 Root 提案被拒绝。删除占位文件后，它等待三次间隔探测，再验证提案恢复。临时 Store、镜像、进程和本地 `HOME` 都位于脚本创建的临时目录，退出时一并清理，不会读取或修改用户的 `/var/lib/dubi` 或 `~/.dubi`。

可用环境变量调整实验而不改变产品默认值：`DUBI_LAB_SIZE_GIB`（默认 `2`）、`DUBI_LAB_TARGET_FREE_KIB`（默认 `900000`）和 `DUBI_LAB_PORT`（默认 `17443`）。它是开发证据，不是生产资格；脚本默认不由全量门禁自动调用。
