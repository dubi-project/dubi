这仍不是完整生产集群：身份、Raft、网络、Root 最小目录、路由/事务、共享混合 Pack 和 Root/Capability 文件快照已有实现与本地验证；不代表完整 Placement、Volume 迁移、备份或具体 Record/File/Search 能力已完成。通用 Handler/Mux 允许空注册集启动控制面，但会拒绝全部未注册能力请求。

Volume 已有默认/显式卷、持久身份、容量与按文件系统预约，Node Pool 支持多卷；在线管理、全引擎资源准入、均衡、安全移除、GC/Compaction 和通用备份资源清单仍未完成。Root/Capability 文件快照已接到正式 Server/Node；全链路内存/磁盘预约和慢 WAN/滚动升级还需继续，详见流式快照实施记录。

内部 Group、Range/Capability RPC、成员持久任务/协调器、远端一次性 enrollment 与 Root learner 加入 CLI 已连通；正式托管流程已另行接入自动 Root 投票角色变更。数据成员 Add/Promote/Remove 已进一步绑定原任务/epoch 与持久成员位置 CAS；准备加入也保留原任务直至 Node 工厂，领导权转移及内部重试另核对成员切点和 term，见[成员任务与位置栅栏](group-membership.md)。Router 不是 Tenant 授权边界。证书完整生命周期、区域数据多数、故障域/容量维护预检和公开 API 尚未完成。Root/Owner 仅支持 Dataset 初始完整 Range；Split、Owner 迁移、Epoch 更新/退役、长事务/扫描/Watch 等需各自受控协议，不可直接改描述符。不能据此直接实施生产 Drain。

三节点快照测试现在包含真实 capability 状态机、磁盘 Pack 和 Server/Node 正式路径；其本机多目录环境仍不能代表物理介质、独立主机或 Region 故障资格。所有完成项以当前 DUBI 证据为准，不沿用 Byfile 历史通过记录，生产结论见 production-readiness.md。
