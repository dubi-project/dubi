# 协议与磁盘格式兼容

DUBI 的控制协议和本地持久格式由 `internal/platform/protocol` 集中声明。节点启动时先校验自身的协议范围、engine 状态机格式和 Pack 容器格式；不认识的格式直接拒绝打开，不尝试猜测或原地修复。

当前版本：

- 控制协议版本 `1`；当前与最小兼容版本均为 `1`。
- engine 状态机格式 `7`。
- Pack 容器格式 `2`，Pack catalog 格式 `2`。
- 不可变记录索引格式 `1`。

Root discovery 响应会携带协议范围、状态机格式、Pack 格式和记录索引格式广告，便于加入节点在真正加入前发现不兼容。协议版本采用范围交集协商；状态机、Pack 和记录索引属于同一持久一致性边界，必须精确匹配，不能只因为 RPC 版本相同就继续运行。

兼容策略保持简单：小版本兼容由协议范围明确表示；不兼容时停止加入或启动，由管理员升级/迁移后重试。不会自动降级为旧的内联数据语义，也不会把未知 Pack 当成空数据。真正的滚动升级、格式迁移工具和跨版本长时间联测仍属于生产资格工作，不在底座开发阶段假装完成。
