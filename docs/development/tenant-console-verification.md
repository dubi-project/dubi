## 自动化与真实接口

- 前端 TypeScript 检查、生产构建、嵌入 DUBI 完成。
- Root 账号范围、全局账号名唯一、最后管理员保护、角色撤销会话、快照保留归属测试通过。
- Auth 包测试在 VPS 通过。
- HTTP 包测试在 VPS 通过；最新授权改动重新运行租户权限、账号登录、Config 拒绝越权用例通过。
- 浏览器模拟三种租户角色通过，均未发起系统管理 API 请求；覆盖手机布局及个人资料。
- `scripts/vps_tenant_console_acceptance.py` 在临时 VPS 实际执行 75 项接口检查通过：
  - 同一租户会话在三个 HTTP 入口可用；用户名全局冲突被拒绝。
  - 三种租户角色均不能访问系统管理和监控管理接口。
  - 非管理员无法管理账号/凭证，跨租户账号/凭证 ID 隐藏为 404。
  - 最后管理员不可停用；归属不可修改。
  - Config 实际创建、跨入口读取、修改、删除成功；不同租户同 Key 隔离；只读写入拒绝。
  - 只读业务 Token 可读不可写，撤销后失效，已撤销记录可删除。
  - 凭证模块不能超出租户授权；身份覆盖参数被拒绝。
  - 修改角色、密码、停用使原会话失效；个人资料可修改。
  - 系统账号列表按归属筛选，归属和角色返回正确。
